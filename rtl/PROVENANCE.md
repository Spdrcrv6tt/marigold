`git -C D:\poinsetta -c core.autocrlf=false archive 1719528 <paths> | tar -x -C D:\marigold` (read only; nothing
written to D:\poinsetta). The directory layout is Poinsetta's, so `git diff --no-index` against a Poinsetta checkout
of 1719528 shows only the edits listed here. Module names keep their imh_ prefix for the same reason.

## Later additions (2026-11-15, overnight build)

- Copied byte-identical from 1719528 for reference and diffs: rtl/core/imh_core.sv, rtl/top/imhotep_top.sv (not
  built). Marigold's core is rtl/core/mg_core.sv, generated from imh_core.sv by a scripted edit: no UART, PDM
  controls or segment registers; island bridge at 0x3000_0000; fan-out array parameter FAN_L (16).
- rtl/top/mg_capture.sv: from imh_capture.sv; the rec- and VAD-gated segmenters replaced by the wake-gated rule of
  docs/architecture.md 8.1; end-marker TIMEOUT flag; WAKE / TIMEOUT event outputs; bank power window = pre-roll;
  the island side of the core's toggles resyncs while the core is off. Reader, queue, bank power and
  oscillator control are Poinsetta's.
- New (Marigold): rtl/top/marigold_top.sv, mg_ctl.sv, mg_cfg_load.sv, mg_cfg_ram.sv, mg_match.sv, mg_msg.sv,
  mg_gpio.sv, mg_i2c.sv, mg_wake_stub.sv; rtl/model/mg_model.py (reference model of the island rules, also used by
  sw/golden/chip_golden.py); rtl/tb/mg_util.py, mg_cfg_tb.sv, test_cfg.py, test_ctl.py, test_cap.py and their
  block.mk entries (cfg, ctl, cap); rtl/top/tb/mg_main.cpp (whole-chip harness).
- rtl/core/imh_rom.svh now holds the LUT ROM of the current model export (written by rtl/core/tools/mkimage_mg.py
  rom; the tables are part of the hardwired ROM image); Poinsetta's original is kept as rtl/core/imh_rom_poinsetta.svh.
  The core unit test test-mac still compiles its C reference against Poinsetta's layout.h fixtures, so its LUT
  operations need the Poinsetta table (swap back, or point the fixtures at the export's layout.h).
- rtl/core/imh_mem.sv: imh_wsrc_rom takes +img=<hex> in simulation (negative controls swap the ROM image without a
  rebuild); synthesis unchanged.
- marigold_top: the core domain's reset asserts asynchronously when core_on falls (found by the whole-chip run: with
  the clock stopped first, the core kept its state across a power-off and the sample handshake desynchronised).
